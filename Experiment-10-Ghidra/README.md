# Experiment 10: Reverse Engineering and Malware Analysis using Ghidra

## Objective
To perform static reverse engineering on compiled executable binaries to understand malware functionality, extract embedded strings, and analyze capabilities without executing the payload.

## Tool Utilized
* **NSA Ghidra**: A powerful, open-source software reverse engineering (SRE) framework developed by the National Security Agency, utilized for disassembling and decompiling code.

## Cybersecurity and Forensic Metrics Applied
* **Malware Analysis Metrics**: Measurement of static analysis coverage, success rates in identifying cryptographic routines, API call resolution, and uncovering obfuscated logic structures.
* **Incident Response Metrics**: Accelerating the generation of Indicators of Compromise (IoCs) and YARA rules based on statically identified malware characteristics.

## Artifacts in this Directory
* `Exp_10.pdf` / `Exp_10.docx`: Step-by-step methodology and documented procedure.
* `Results/`: Decompiled code snippets, extracted string arrays, and function graph analyses.
* `Screenshots/`: Visual confirmation of the disassembler view, decompiled C-code window, and program trees.
