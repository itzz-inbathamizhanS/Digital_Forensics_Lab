# Experiment 02: Data Recovery using TestDisk

## Objective
To recover lost or deleted partitions and restore corrupted or deleted data from various storage media.

## Tool Utilized
* **TestDisk**: Powerful open-source data recovery software designed to help recover lost partitions and make non-booting disks bootable again.

## Cybersecurity and Forensic Metrics Applied
* **Data Recovery Metrics**: Quantification of the percentage of successfully recovered fragmented files, restoration accuracy for corrupted partition tables, and file system reconstruction capabilities.
* **Data Integrity Metrics**: Ensuring that the recovery process does not overwrite existing unallocated space critical for further forensic analysis.

## Artifacts in this Directory
* `Exp_2.pdf` / `Exp_2.docx`: Step-by-step methodology and documented procedure.
* `Results/`: Recovered files and partition structural logs.
* `Screenshots/`: Visual confirmation of the partition mapping and data extraction phases.
