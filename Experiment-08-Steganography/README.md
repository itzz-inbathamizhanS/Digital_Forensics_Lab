# Experiment 08: Data Hiding and Steganalysis (Steganography)

## Objective
To practically understand data obfuscation by embedding payloads within carrier files (images/audio) and to perform steganalysis to detect, isolate, and extract hidden data.

## Tools Utilized
* **Steganography Tools** (e.g., OpenStego, Steghide, ExifTool): Software designed to hide secret information within a non-secret carrier file and conversely analyze files for anomalous data signatures.

## Cybersecurity and Forensic Metrics Applied
* **Malware Analysis Metrics**: Evaluation of payload extraction rates and identification of obfuscated command-and-control communication mechanisms.
* **Data Integrity Metrics**: Measurement of carrier file distortion, structural anomalies in headers/footers, and Least Significant Bit (LSB) manipulation detection.

## Artifacts in this Directory
* `Exp_8.pdf` / `Exp_8.docx`: Step-by-step methodology and documented procedure.
* `Results/`: Carrier files (before and after), extracted payloads, and steganalysis reports.
* `Screenshots/`: Visual confirmation of the embedding and extraction procedures.
