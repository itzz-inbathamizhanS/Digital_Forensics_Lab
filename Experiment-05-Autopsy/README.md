# Experiment 05: Disk Analysis and Investigation using Autopsy

## Objective
To conduct a comprehensive disk forensic investigation, including keyword searching, timeline analysis, and extraction of system artifacts using an integrated digital forensics platform.

## Tool Utilized
* **Autopsy**: The premier open-source digital forensics platform and graphical interface to The Sleuth Kit, used for investigating hard drives and smartphones.

## Cybersecurity and Forensic Metrics Applied
* **Data Recovery Metrics**: Efficiency in identifying hidden or deleted system artifacts, browser histories, and registry hives.
* **Incident Response Metrics**: Accuracy in reconstructing the timeline of events (MACB times) to trace user activity or unauthorized system modifications.
* **Data Integrity Metrics**: Maintaining the integrity of the data source by utilizing read-only volume access throughout the investigation.

## Artifacts in this Directory
* `Exp_5.pdf` / `Exp_5.docx`: Step-by-step methodology and documented procedure.
* `Results/`: Exported timeline CSVs, keyword search hits, and extracted artifacts.
* `Screenshots/`: Visual confirmation of the Autopsy module results and artifact analysis.
