# Experiment 03: Network Traffic Analysis using Wireshark

## Objective
To capture, filter, and perform deep packet inspection on network traffic to identify protocol anomalies, plain-text credentials, and malicious communication patterns.

## Tool Utilized
* **Wireshark**: The world’s foremost and widely-used network protocol analyzer, allowing for micro-level visibility into network traffic.

## Cybersecurity and Forensic Metrics Applied
* **Network Security Metrics**: Measurement of protocol anomaly detection rates, identification of unencrypted sensitive data transmission, and accurate isolation of malicious TCP/UDP streams.
* **Incident Response Metrics**: Utilizing packet capture (PCAP) files to establish the Mean Time to Detect (MTTD) indicators of compromise across the network layer.

## Artifacts in this Directory
* `Exp_3.pdf` / `Exp_3.docx`: Step-by-step methodology and documented procedure.
* `Results/`: PCAP files and filtered stream data.
* `Screenshots/`: Visual confirmation of specific packet anomalies and protocol hierarchy statistics.
